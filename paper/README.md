# Paper sources

`acl.sty` and `acl_natbib.bst` are the official ACL style files from acl-org/acl-style-files at commit d5adc823ff0f80f98c80405ca0ab66c68e684409.
`numbers.tex`, `tables/` and `../CLAIMS.md` are generated by `scripts/paper_numbers.py`; `figures/` by `scripts/make_figures.py`. Do not edit them by hand.
